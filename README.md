# V2HUB Android Application

Ready-to-build Android project with custom V2HUB branding, neon-green/dark theme, launcher icons, subscription & config parser (VLESS, VMess, Trojan, Shadowsocks, SOCKS), real TCP/TLS delay tester, bilingual support (FA/EN), and Telegram buttons (`t.me/v2hubir` & `t.me/v2hubvip`).
